A personal portfolio website for **Nigel Muchende Kyalo**, a Full-Stack Web Developer, Web Designer, and AI Integration specialist based in Nairobi, Kenya — serving clients across Kenya and the United Kingdom.

## About

This is a fully responsive, single-page portfolio website built with pure HTML, CSS, and vanilla JavaScript — no frameworks, no build tools, no dependencies. It showcases services, selected projects, client markets, SEO expertise, and AI integration capabilities.

---

## Features

- ☀️ **Light / Dark Mode** — Toggle with persistent preference saved to localStorage; respects system preference on first load
- 📱 **Fully Responsive** — Mobile-first design tested across all screen sizes
- ⚡ **Zero Dependencies** — Pure HTML/CSS/JS, no npm, no build step required
- 🎨 **Animated Hero** — Staggered fade-up entrance animations
- 🔁 **Marquee Ticker** — Scrolling skills and services banner
- 🗂️ **Services Modal** — Click-to-expand detailed service pages with smooth overlay
- 🌍 **Dual Market Positioning** — Kenya 🇰🇪 and United Kingdom 🇬🇧 client sections
- 🔠 **Google Fonts** — Playfair Display + DM Sans type pairing

## Getting Started

No build step needed. Just open the file:

```bash
# Clone the repo
git clone https://github.com/Nigelkyalo/nmk-portfolio.git

# Open in browser
open index.html
```

Or deploy instantly:

- **GitHub Pages** — Push to `main`, enable Pages in repo Settings → Pages → Deploy from branch
- **Netlify Drop** — Drag `index.html` to [app.netlify.com/drop](https://app.netlify.com/drop)
- **Vercel** — Import repo and deploy with zero config
